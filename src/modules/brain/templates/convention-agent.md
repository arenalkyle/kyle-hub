# Agent style conventions

- Terse. Imperative sentences. No filler.
- One fact per bullet. Use the glossary terms exactly.
- Commands in backticks, runnable as written.
- Acceptance criteria: checkboxes, each one verifiable.
- Never invent paths, flags or APIs. Check the repo first.
- Report: what changed, tests run, what is left.
- Templates for agents live in `.kyle-hub/templates/` (vault root). You may edit them to fit the work.
